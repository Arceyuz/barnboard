# Barnboard

**Open the app (tap this):** https://barnboard-wd.netlify.app

That is the working board. This GitHub page is only the source code.

Coverage, surgery days, and close-out for Dr. Weston Davis’s equine practice. Same extras as WD Crew Board: I am picker, Week / Day / Team & duties, duty checklists, surgery-day chips, and Fill from usual days. It can read the shared **Appointments** Google Calendar. It never writes back, and it never shows medical notes, phone numbers, or card numbers.

## How to try it

1. Open https://barnboard-wd.netlify.app
2. Set **I am** → Alejandro
3. Stay on **Day** for Tuesday Sep 15 (Surgery)
4. Check **Sterile prep** and **Stage the surgery pack**
5. Open **Week** and switch **Day / Week / Month**. Week is stacked day cards. Month is a Mon–Sat grid. Tap a day to open duties.
6. Open **Team & duties** to edit workdays, trucks, and the duty library
7. Tap **Load my calendar** to pull live Appointments. Prev/next loads that range.
